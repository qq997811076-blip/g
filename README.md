IPv4测速工具

一款基于 Android + Go 的 IPv4 批量筛选与下载测速工具，提供「个性优选」和「官方优选」两种模式。

一、核心功能

1. 个性优选

- 支持 TXT、CSV 文件导入 IP。
- 支持剪贴板导入。
- 支持多个网络 URL 导入，每行一个 URL。
- 支持 IPv4 提取、CIDR 网段展开、无效地址过滤和去重。
- 支持本地文件和网络 URL 来源独立启用或关闭。

2. 官方优选

- 获取 Cloudflare 官方 IPv4 网段，随机抽取不重复的 IPv4 地址。
- 自动进行 HTTPS 连通性检测。
- 识别 Cloudflare 数据中心、国家或地区。
- 按数据中心分类显示合格 IP。
- 支持指定数据中心单独测速。
- 支持自动选择最低延迟的数据中心。
- 复用已通过连通性检测的 IP，避免重复检测。

二、主要测速参数

参数| 默认值| 作用
连通性并发数| 1000| 同时检测的 IP 数量
下载测速并发数| 3| 同时测速 IP 数量
低延迟 IP 数量| 10| 参与下载测速的 IP 数量
最低显示速度| 0.5 MiB/s| 过滤低速结果
下载上限| 5 MiB| 单个 IP 下载数据上限
单 IP 测速时间| 5 秒| Go 核心测速时间

关闭下载上限开关后，Go 核心使用测速地址 URL 中设置的下载上限。

三、测速地址

- 自动选择：根据运营商自动选择。

自动选择规则：

- 中国移动：移动专属地址。
- 中国联通、中国电信及其他运营商：Cloudflare 地址。

四、数据来源

- Cloudflare 官方 IPv4 网段："https://www.cloudflare.com/ips-v4"

五、GitHub 上传设置

- GitHub Token：用于授权上传。
- 用户名：GitHub 账号名称。
- 仓库：指定上传目标仓库。
- 分支："main"
- 文件路径："ip.txt"
- 上传方式：支持覆盖上传和追加上传。
- 自动上传：测速完成后自动上传结果。
- 手动上传：支持手动测试上传。
- 保存设置：保存 GitHub 上传配置。
